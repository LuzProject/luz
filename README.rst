Luz
---------------------
Luz is a next-generation build system targeting Apple Darwin-based systems.
Luz comes with out-of-the-box support for macOS and Linux.

Installing
*********************

Installation is incredibly simple and instructions on how to do so can be found in the `docs <https://luz.jaidan.dev>`_.

This will install the latest version of Luz to your system.

Credits
*********************

Luz vendors and calls the native Python Logos interpreter, `pyLogos
<https://github.com/iCrazeiOS/pyLogos>`_. Thank you to `iCrazeiOS
<https://github.com/iCrazeiOS>`_ for creating and maintaining it. Logos
sources are processed in-process, without launching a separate Python command
for every ``.x`` or ``.xm`` file.
